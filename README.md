# CinemaCrop 🎬

Android-приложение на **Kotlin + Jetpack Compose** для кадрирования фото
в кинематографических соотношениях сторон.

## Возможности

- Пресеты киноформатов: **IMAX 1.43:1, 4:3, 1:1, 1.66:1, 16:9, 1.85:1 (Universal),
  2.39:1 (Anamorphic Scope), 2.59:1 (Cinerama), 21:9**, а также «Оригинал».
- Интерактивная рамка кадрирования: перетаскивание и зум щипком (pinch),
  слайдер зума, сетка «правило третей», затемнение вне рамки.
- Поворот изображения на 90° с корректным пересчётом кадра.
- Чтение метаданных EXIF (фото всегда отображается в правильной ориентации).
- Сохранение результата в галерею (`Pictures/CinemaCrop`) через MediaStore —
  без разрешений на Android 10+.
- Даунсемплинг больших фото (до 4096 px) для экономии памяти.

## Структура проекта

```
app/src/main/java/com/example/cinemacrop/
├── MainActivity.kt              // точка входа, выбор фото (Photo Picker)
├── ui/CropScreen.kt             // Compose UI: canvas, рамка, жесты, пресеты
└── util/
    ├── AspectRatioPreset.kt     // перечисление киноформатов
    ├── CropUtils.kt             // математика кадрирования (рамка, pan/zoom, вырез)
    └── ImageIO.kt               // загрузка (EXIF) и сохранение изображений
```

## Сборка

Откройте проект в Android Studio (Hedgehog или новее) и нажмите **Run**, либо:

```bash
./gradlew assembleDebug
# APK: app/build/outputs/apk/debug/app-debug.apk
```

Требования: JDK 17, Android SDK 34, minSdk 24.

## Как пользоваться

1. Нажмите **«Выбрать фото из галереи»** (или иконку галереи сверху).
2. Выберите нужный формат внизу экрана (например, **2.39:1** — широкий экран).
3. Перемещайте и масштабируйте фото пальцами так, чтобы всё важное попало в рамку.
4. При необходимости поверните фото кнопкой ↻.
5. Нажмите 💾 — кадр сохранится в `Pictures/CinemaCrop`.
